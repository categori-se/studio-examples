# Workbench Examples

Safe local demos and self-hosting templates for the public Workbench packages.

Run the deterministic local example after installing the workspace dependencies:

```bash
node local-demo/demo.mjs
```

The deployment directory contains placeholders only. Supply your own isolated account, domain, identity, and least-privilege policy. No hosted-service configuration or customer content belongs in this repository.
